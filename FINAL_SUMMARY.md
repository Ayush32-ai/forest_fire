## 🚀 How to Run

### Step 1: Install Dependencies
```bash
cd forest_fire
flutter pub get
```

### Step 2: Run the App
```bash
flutter run
```

### Step 3: Connect to ESP32
1. Enter your ESP32 IP when prompted
2. Wait for "Connected" status
3. See real-time data in Monitor tab

### Step 4: See the Magic! ✨
1. Tap the **Analytics** tab
2. Watch the Fire Risk Score update in real-time
3. View beautiful charts and trends
4. Get AI-powered recommendations
5. Explore GitHub wildfire research
