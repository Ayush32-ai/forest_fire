🎓 **KEY SECTIONS TO KNOW:**

Alert Thresholds:
  - Temperature: 35°C (high), 10°C (low)
  - Humidity: 80% (high), 30% (low)
  - Smoke: Auto-calibrated threshold

API Endpoints:
  - GET /api/sensors (sensor data)
  - GET /api/status (device status)
  - GET /health (health check)
  - GET / (HTML dashboard)

Pin Configuration:
  - MQ-2 Sensor: GPIO34
  - DHT Sensor: GPIO4
  - LED Alert: GPIO2
  - Buzzer: GPIO5

🐛 **QUICK TROUBLESHOOTING:**

Issue: WiFi won't connect
→ Check SSID/password in code (lines 24-25)
→ Ensure 2.4GHz WiFi network
→ See README_SETUP.md for details

Issue: DHT sensor shows error
→ Check 3.3V power to sensor
→ Verify GPIO4 connection
→ See TESTING_GUIDE.md for diagnostics

Issue: App shows "Disconnected"
→ Find ESP32 IP from Serial Monitor
→ Verify both on same WiFi network
→ Check firewall settings

Issue: Smoke sensor reading always high
→ Ensure 20-second warm-up period
→ Calibrate in fresh air
→ Check GPIO34 connection

Full troubleshooting: See TESTING_GUIDE.md
